# URSTAR — Frontend
SPA на React + TypeScript для маркетплейса одежды: поиск и фильтрация товаров, создание и сохранение outfit’ов, корзина, избранное, отзывы и пользовательские профили.


URSTAR - Что может делать пользователь на сайте
---
URSTAR — интернет-магазин уличной моды с уникальной функцией комбинирования одежды.
После входа или регистрации вы получаете доступ ко всем возможностям сайта.
В каталоге можно искать товары по названию и бренду и фильтровать по категориям (верхняя одежда, низ, обувь, аксессуары). На каждом товаре есть кнопки для добавления в корзину, избранное или или использовать товар для комбинирования одежды.
Подробная страница товара показывает фото, описание, цену, дает возможность выбрать размер и добавить в корзину. Здесь также видны отзывы от купивших.
Комбинирование одежды — главная фишка сайта. Вы собираете образ: выбираете верх, низ, обувь и аксессуар. Можно назвать образ и сохранить его, потом поделиться в соцсетях.
В корзине кнопки для изменения количества товаров и удаления. Автоматически считается сумма.
В избранном хранятся сохраненные товары. В личном кабинете — профиль, мои образы, любимые товары и история покупок.
Купившие товар пользователи могут оставлять отзывы с оценками.
Админы могут добавлять, редактировать и удалять товары, видеть список всех пользователей.

Роль
---
Реализация клиентской логики, интерфейсов, форм и интеграции с REST API сервера.

Стек
---
- React, TypeScript, Vite
- Redux, redux-thunk
- React Router, react-hook-form, yup
- Sass, Tailwind (при необходимости)

Структура (кратко)
---
- `src/pages/` — маршруты и страницы
- `src/components/` — UI и логика компонентов
- `src/store.ts`, `src/reducers/`, `src/actions/` — Redux
- `src/hooks/` — кастомные хуки
- `src/utils/` — вспомогательные функции

Ключевая функциональность
---
- Авторизация/регистрация, хранение пользователя в Redux
- Просмотр, поиск и фильтрация товаров
- Cart и Favorites с локальным/серверным состоянием
- Outfit builder: создание, просмотр и сохранение комплектов
- Валидация форм через `react-hook-form` + `yup`
